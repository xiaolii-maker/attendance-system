# 班级考勤管理系统

## 项目简介
本项目是一个基于 Spring Boot 开发的班级考勤管理系统，旨在帮助教师高效管理学生考勤，学生可随时查看个人考勤记录。系统提供完整的考勤打卡、记录查询、批量导入导出等功能，支持多角色权限管理。

## 功能模块

### 1. 用户管理
- 用户注册：支持学生、教师、管理员注册
- 用户登录：Spring Security 安全认证
- 密码加密：BCrypt 加密存储

### 2. 学生管理
- 学生信息增删改查
- 分页查询
- 按班级、姓名搜索
- 批量导入学生（Excel）

### 3. 考勤打卡
- 选择课程打卡
- 自动获取当前时间
- 迟到自动判断
- 打卡时间限制（开始前15分钟至开始后30分钟）
- 打卡备注功能

### 4. 考勤记录
- 个人考勤历史查看
- 按日期范围筛选
- 按状态筛选（正常/迟到）
- 分页展示

### 5. 批量导入
- Excel 文件上传
- 支持 .xlsx / .xls 格式
- 数据验证（学号、课程存在性）
- 导入结果反馈（成功/失败统计）
